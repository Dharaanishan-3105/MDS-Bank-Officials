Security hardening updates (Netlify + basic HTML hardening)

1) Added Netlify header configuration:
- File: netlify.toml
- Headers:
  - X-Content-Type-Options: nosniff
  - Referrer-Policy: strict-origin-when-cross-origin
  - X-Frame-Options: DENY
  - Permissions-Policy: geolocation=(), microphone=(), camera=()

Notes:
- Because Chrome Safe Browsing reputation/flags cannot be fixed purely via code changes, these headers reduce risk and improve baseline security.
- External tracking (GTM/YouTube) was intentionally left untouched per your requirement.
